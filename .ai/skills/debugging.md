# Skill: Evidence-Driven Debugging

1. State exact observed failure.
2. Separate observations from assumptions.
3. Collect cheapest relevant evidence.
4. Rank hypotheses.
5. Test one discriminating hypothesis at a time.
6. Avoid broad changes.
7. Verify root cause.
8. Implement smallest causal fix.
9. Re-run verification.
10. Add regression coverage when appropriate.
11. Remove temporary diagnostics.

Do not:
- retry blindly;
- modify unrelated areas;
- weaken validation/security;
- promote hypotheses into durable memory.
